Lantana Travel — 架空の高級旅行会社Webサイト

使い方
1. index.html をダブルクリックしてブラウザで開いてください。
2. styles.css と script.js は index.html と同じフォルダに置いてください。
3. Netlifyに公開する場合は、ZIPを解凍したフォルダをドラッグ＆ドロップしてください。

主な機能
- PC・スマホに対応したレスポンシブデザイン
- 行き先・旅のスタイル・季節での絞り込み
- 旅行先カードをクリックして詳細ダイアログ表示
- 旅のスタイル別フィルター
- スマホ用メニュー

注意
- 架空のブランド・架空の旅行商品です。料金、旅程はデモ表示です。
- 画像はUnsplashの外部URLを使用しており、表示にはインターネット接続が必要です。
- 画像は仮素材です。公開時は写真の内容と利用条件を確認し、目的地に合った素材へ差し替えてください。
- お問い合わせ先 hello@example.com は仮のアドレスです。
- 決済・実予約・外部データベースとの接続は実装していません。
